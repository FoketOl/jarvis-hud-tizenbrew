# jarvis-hud-tizenbrew

A [TizenBrew](https://github.com/reisxd/TizenBrew) **application module** that adds a
"JARVIS HUD" tile to a Samsung Tizen TV. Launching it opens a personal, self-hosted
heads-up display served on the local network. Contains only a redirect page and a
`package.json` manifest — no application logic, no credentials.

Add in TizenBrew as module: `gh/FoketOl/jarvis-hud-tizenbrew`

## Afstandsbediening (v1.1.0)
Cijfertoetsen geregistreerd: 5 klok, 6 systeem, 7 camera's, 8 printer, 9 of 0 terug naar de HUD.
